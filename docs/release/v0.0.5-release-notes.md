satisfied — see "What this is not" below. Full evidence:

## What this is

Fornax v0.0.5 adds causal and longitudinal verification infrastructure on
top of v0.0.4's multi-signal integrity engine:

- **Evidence provenance classing** — claims are structurally tagged as
  observational, replayed, or interventional, so a causal claim can never be
  silently confused with a passive observation.
- **Reliability & drift computation** — Wilson-interval statistics over
  adjudicated cohort outcomes with an explicit minimum-sample-support floor;
  refuses to produce a numeric estimate from sparse data rather than
  guessing.
- **Sandboxed counterfactual experiment runner** (`fornax-experiment-runner`)
  — stages an isolated, path-traversal-safe, symlink-safe worktree copy to
  run interventions without touching the source tree or executing any
  subprocess/shell/dynamic code.
- **Local replay engine** (`fornax-replay`) — recomputes a frozen manifest's
  verdict for regression comparison against a prior run.

## What this is not

**Not a proven causal-value claim.** FORNX-107 ([CAUSAL READY]) —
"independently gate on demonstrated causal/longitudinal value and safe
experiment behavior" — remains **open and deferred, not satisfied, not
waived**. Its gate procedure requires representative intervention
experiments, passive-vs-counterfactual comparison on frozen cases, and
contextual-reliability/drift evaluation on held-out comparable cohorts —
none of which can be produced without a real causal-experiment corpus /
labeled longitudinal dataset that does not currently exist. This release
does not fabricate that corpus or lower the gate's evidence threshold. This
gap was escalated as a genuine research/product decision on 2026-09-05 and
reconfirmed on 2026-09-10, the same treatment given to v0.0.4's FORNX-97 gap.

**If you enable the experiment runner or replay engine in this release**,
treat their output as engineering infrastructure for building toward a
causal-value claim, not as evidence that intervention-based verification
already outperforms passive monitoring — Fornax does not yet have real
evidence of that.

## Path to the real causal-readiness claim

[FORNX-343](https://lightning-dust-mite.atlassian.net/browse/FORNX-343)
(Stage 8, "Gold Corpus Bootstrap") is the same shared path toward a real
labeled dataset that FORNX-97 (v0.0.4's deferred gate) also depends on —
this release does not attempt to substitute synthetic or fabricated data for
it. FORNX-107 depends on that same corpus effort.

## Security

Independent security/QA review of the sandboxed experiment runner, replay
engine, causal-provenance types, reliability statistics, retention, and
privacy gating found no findings (`risk_class: FEATURE`, `verdict: PASS`).
A prior, separate privacy/security pass (2026-09-02, part of FORNX-107's own
gate procedure) found and fixed two gaps pre-freeze: an orphaned
staging-directory sweep that wasn't wired into the experiment runner
(Medium), and an observer trait signature gap that limited future
extensibility without being exploitable in the current call path (Low). See
[`docs/release/v0.0.5-qa-signoff.md`](v0.0.5-qa-signoff.md) for detail.

## Migration notes

No breaking changes to existing `Evidence`, `Finding`, `Fusion`, or CLI/API
contracts. All new surfaces (causal provenance, reliability/drift
computation, experiment runner, replay engine) are additive. Two new opt-in
privacy/egress gates (`longitudinal_reliability_collection_allowed`,
`replay_export_egress_allowed`) default closed.
