## What this covers

- **Evidence provenance classing** (`fornax-types/causal.rs`): claims are
  structurally distinguishable as observational, replayed, or interventional
  — the type system prevents constructing an interventional record without a
  real experiment+evidence reference (constructor and serde `try_from` both
  enforce it).
- **Reliability & drift computation** (`reliability.rs`): Wilson-interval
  statistics over adjudicated cohort outcomes, gated by an explicit
  minimum-sample-support threshold. Below threshold, the estimate is `None`
  — never a numeric-looking guess from sparse data. Drift comparison
  requires non-overlapping 95% CIs and rejects non-comparable cohorts.
- **Sandboxed experiment runner** (`fornax-experiment-runner`): stages an
  isolated worktree copy for counterfactual interventions — never touches
  the source tree, path-traversal-safe (`resolve_contained`: canonicalize +
  `starts_with`), symlink-safe (never followed during staging or
  resolution), no subprocess/shell/dynamic-code execution anywhere in the
  crate (confirmed via exhaustive grep).
- **Local replay engine** (`fornax-replay`): recomputes a frozen manifest's
  verdict for regression comparison. No hash/signature — integrity is
  trust-based, consistent with its documented scope as a local-file
  regression tool with no network/multi-party threat model. Informational,
  not a gap.
- **Retention** (`retention.rs`): tenant-triggered deletion is transactional,
  table names matched via literal `match` arms (never SQL-interpolated),
  cross-tenant isolation tested. No automatic time-based sweep exists yet —
  documented in the module's own doc comment as an explicit scope boundary,
  not a silent gap.
- **Privacy gate** (`privacy.rs` additions): `longitudinal_reliability_collection_allowed`
  defaults closed; only exact `"1"`/`"true"` enables it (tested against a
  `"yes"` false-positive).

All four capabilities are additive and touch no existing trust boundary
(`adapter_provider_input`, `evidence_provenance`, `egress_redaction`) — see
"Security review" below for the risk classification.

## What this does NOT cover — and does not claim

**FORNX-107 [CAUSAL READY] remains open, not passed, not waived.** Its gate
procedure requires demonstrating real causal/longitudinal value: running
representative intervention experiments, comparing passive-only vs
counterfactual decisions on frozen cases, and evaluating contextual
reliability/drift on held-out comparable cohorts. None of that can be
produced without a real causal-experiment corpus / labeled longitudinal
dataset, which does not currently exist (escalated 2026-09-05, reconfirmed
2026-09-10 — FORNX-107's own comment thread). This release does not
fabricate that corpus or lower the gate's evidence threshold.

**Privacy/security review of the underlying mechanism was already performed**
(FORNX-107 comment, 2026-09-02) against all 9 Stage-5 surfaces — isolation
boundary, permission gating, causal-provenance construction, cross-tenant
deletion, reliability-privacy aggregation — independently re-traced, not
just doc-read. Two real gaps were found and fixed in that pass (commit
`06fd5d7`, before this candidate's freeze point):
`sweep_orphaned_staging_dirs` not wired into `run_experiment()` (Medium —
killed experiment runs left staged working-tree copies on disk
indefinitely), and `InterventionObserver::observe` taking a bare `&Path`
instead of `&StagedWorktree` (Low — latent gap for a future observer, not
exploitable in the current call path). Both fixed with regression tests.

**A fresh, independent security/QA pass performed for this release** (this
document) re-reviewed `causal.rs`, `reliability.rs`, `retention.rs`,
`fornax-experiment-runner`'s `staging.rs`, the replay manifest/engine, and
`privacy.rs` additions. **No new findings** — statistical correctness,
replay tampering surface, experiment injection surface, causal-correctness
type enforcement, privacy defaults, and retention isolation were all
checked and cleared. See
[`release/v0.0.5-security-signoff.json`](../../release/v0.0.5-security-signoff.json)
(`risk_class: FEATURE`, `verdict: PASS`, `findings: []`).

**Follow-up path (linked, not duplicated):** [FORNX-343](https://lightning-dust-mite.atlassian.net/browse/FORNX-343)
(Stage 8, "Gold Corpus Bootstrap") remains the shared, reused path toward
