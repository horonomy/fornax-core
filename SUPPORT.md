# Support

Fornax is currently maintained by a single maintainer, not a formal support
team. This page describes the real, currently-available channels honestly —
it does not promise a response-time SLA that isn't backed by operational
evidence yet.

## Reporting a bug or requesting a feature

Open a [GitHub Issue](https://github.com/horonomy/fornax-core/issues/new/choose)
using the bug report or feature request template. This is the primary,
currently-supported channel.

## Security vulnerabilities

Do **not** open a public issue for a security vulnerability. See
[`SECURITY.md`](SECURITY.md) for private disclosure via GitHub Security
Advisories.

## Code of conduct violations

See [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) for how to report a conduct
concern.

## Response expectations

There is no guaranteed response-time SLA at this stage of the project — see
[`SECURITY.md`](SECURITY.md)'s "Response Expectations" section, which states
the same honestly for vulnerability reports. General issues are triaged as
maintainer time allows. This will be revisited once Fornax has real
operational evidence to back a formal support commitment (tracked under
FORNX-367).
