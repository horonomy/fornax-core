# Security Policy

## Supported Versions

Fornax is pre-1.0 and under active development. Only the latest commit on
`main` is supported for security fixes — there is no maintained release
branch to backport to at this stage.

| Version       | Supported          |
| ------------- | ------------------- |
| `main` (HEAD) | :white_check_mark:  |
| Older commits | :x:                 |

## Reporting a Vulnerability

Please **do not open a public GitHub issue** for security vulnerabilities.

Instead, report it privately using [GitHub Security Advisories](https://github.com/horonomy/fornax-core/security/advisories)
for this repository — use the "Report a vulnerability" button on that page.
If private reporting is not yet enabled when you visit, please reach out to
the maintainer ([@Chisanan232](https://github.com/Chisanan232)) directly via
GitHub instead of filing a public issue. This lets us discuss and fix the
issue before it's publicly disclosed.

## Response Expectations

`fornax-core` is currently maintained by a single maintainer, not a formal
security team. There is no guaranteed SLA. As a general expectation:

- You should receive an initial acknowledgement within a few business days.
- Confirmed vulnerabilities will be prioritized over other work, but a fix
  timeline depends on severity and complexity — there is no fixed turnaround
  commitment at this stage of the project.

Thank you for helping keep Fornax and its users safe.
